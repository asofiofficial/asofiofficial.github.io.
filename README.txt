ASOFI WEBSITE STARTER
====================

Files:
- index.html: website structure
- styles.css: design and responsive styling
- script.js: sample products, filters and demo shopping bag
- assets/asofi-logo.png: your supplied ASOFI logo

PREVIEW:
Open index.html in a browser.

IMPORTANT BEFORE SELLING:
This is a free static website starter, not a live connected store yet.
The sample products and prices are placeholders. Replace them with your actual Printify products.
The shopping bag is a front-end demo; checkout, payment processing, order submission, shipping updates,
newsletter collection, policies and customer accounts are not connected.

PRINTIFY:
To connect Printify securely, add a server-side backend or use a supported e-commerce platform integration.
Never put a Printify API token in index.html or script.js. A secure integration needs your Printify shop ID,
API credentials stored as server secrets, product/variant mapping, order creation and fulfillment webhooks.

FREE HOSTING:
You can publish the static preview using GitHub Pages or Netlify's free tier.
Upload the contents of this folder (not just the ZIP) to your hosting provider.
